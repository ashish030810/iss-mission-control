# 🛰️ Live ISS Tracker – WebOS App

A real-time International Space Station tracker built as a draggable app for a WebOS desktop.

## Features
- Live ISS position on a dark map
- Real-time latitude and longitude
- Astronaut count in space
- Auto-refresh every 10 seconds
- Space-themed UI

## Built With
- HTML, CSS, JavaScript
- Leaflet.js for mapping
- Open Notify API for ISS and astronaut data

## How to Run
1. Clone this repo
2. Open `index.html` in your browser
3. Watch the ISS move in real-time!
